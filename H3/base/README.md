# H3 - Base

Esta implementación representa el problema inicial sin aplicar patrones de diseño.

El dominio utiliza Documento, Usuario, Unidad y Derivacion.

Un Documento puede ser derivado a un Usuario, quien pertenece a una Unidad.

Esta versión sirve como punto de comparación para demostrar cómo cada patrón mejora o reorganiza una parte específica del diseño.

El objetivo es que cada patrón de H3 se estudie de forma aislada.
